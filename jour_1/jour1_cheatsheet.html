Jour 01 — Cheatsheet

Types · Variables · Mutabilité · try/except · Duck Typing
mémos techniques
Variable = étiquette, pas boîte
En Python, une variable pointe vers un objet en mémoire. Deux variables peuvent pointer vers le même objet. Copier une liste avec b = a ne crée pas de copie — utilise b = a.copy().
Typage dynamique
Python détecte le type à l'exécution, pas à la déclaration. Une variable peut changer de type. Utilise type(x) pour inspecter et isinstance(x, int) pour valider.
Immuable vs Mutable
Immuables (non modifiables) : str, int, float, tuple, bool.
Mutables (modifiables) : list, dict, set.
Lire un immuable = OK. Modifier = TypeError.
input() retourne TOUJOURS str
Peu importe ce que l'utilisateur tape, input() retourne une string. C'est float() ou int() qui peut lever ValueError, pas input() lui-même.
== vs is
== compare les valeurs.
is compare les adresses mémoire via id().
Règle pro : n'utilise is que pour x is None.
Duck Typing
Python ne vérifie pas le type — il vérifie si l'objet peut faire ce qu'on lui demande. "ha" * 2 = "haha". Flexibilité maximale, rigueur nécessaire.
