Jour 02 — Cheatsheet

Boucles · for · while · range() · break · continue · Patterns
mémos techniques
for vs while
for → nombre d'itérations connu à l'avance.
while → on boucle tant qu'une condition est vraie. Nombre d'itérations inconnu.
range() — bornes
range(n) → de 0 à n-1.
range(a, b) → de a à b-1. La borne droite est toujours exclue.
range(a, b, step) → avec un pas.
break vs continue
break → stoppe la boucle immédiatement.
continue → saute le reste de l'itération en cours et passe à la suivante.
while False dès le départ
Si la condition est fausse dès le début, le corps de la boucle ne s'exécute jamais. Python vérifie la condition avant chaque itération, y compris la première.
Pattern : boucle jusqu'à succès
while True + break = pattern standard quand on ne connaît pas le nombre de tentatives. Plus propre qu'un drapeau booléen.
Factorisation dans les boucles
Si deux branches d'un if/elif font la même chose, sors ce code du if. Ne répète jamais une instruction qu'on peut écrire une seule fois.

while_patterns.py
# ── while classique ───────────────────────────────── compteur = 0 while compteur < 5: print(compteur) compteur += 1 # → 0 1 2 3 4 # ── PATTERN PRO : while True + break ──────────────── while True: # ✓ boucle infinie contrôlée try: valeur = int(input("Entrez un nombre : ")) except ValueError: print("Nombre invalide, réessayez") else: break # sortie propre si succès # ── ANTI-PATTERN : drapeau inutile ────────────────── is_invalide = True # ✗ inutile while is_invalide: ... is_invalide = False # ✗ remplacer par while True + break
factorisation.py
# ── ANTI-PATTERN : répétition dans if/elif ────────── if reponse > nombre: print("Trop grand") counter = counter + 1 # ✗ répété dans chaque branche elif reponse < nombre: counter = counter + 1 # ✗ print("Trop petit") # ── PATTERN PRO : factoriser ce qui est commun ────── counter += 1 # ✓ une seule fois, avant le if if reponse > nombre: print("Trop grand") elif reponse < nombre: print("Trop petit") else: print("Bravo !") break # ── += est du sucre syntaxique ─────────────────────── counter += 1 # identique à counter = counter + 1 counter -= 1 # counter = counter - 1 counter *= 2 # counter = counter * 2
